# Soulforge development plan

Source of scope: MasterPromt.txt §§1–26. Dependencies follow the numbers below. Every milestone requires a runnable desktop game, typecheck, lint, relevant tests, browser smoke test and production build. Record evidence before advancing.

| Milestone                        | Depends on          | Work                                                                                                                                                                                                                                                                 | Acceptance                                                                                                                                                                                                                   |
| -------------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 · Foundation                   | Existing repository | Lock React, Vite, TypeScript, Babylon and Firebase dependencies. Add routes, error/loading states, config validation, development scripts, formatting, lint, Vitest, RTL and Playwright.                                                                             | Clean install starts the dev server. Menu and WebGL scene render. Missing Firebase configuration is visible. Build succeeds.                                                                                                 |
| 2 · Playable world               | 1                   | Connect village, woods and ruins with terrain, props, paths, lighting, original humanoid, idle/walk/run/jump, camera-relative movement, sprint, orbit, zoom, collisions and boundaries.                                                                              | Traverse each area, jump and orbit. Major solids block travel, camera avoids clipping and browser console stays clean.                                                                                                       |
| 3 · Character and combat         | 2                   | Centralize six attributes, derived stats, level 1–10 XP curve, resources and allocation. Implement targeting, range, sight, typed damage, criticals, AI patrol/aggro/leash/respawn, death, rewards and HUD.                                                          | Defeat a hostile that can fight back, gain XP, level and spend points. Resource costs, timing, damage bounds, death and respawn pass tests.                                                                                  |
