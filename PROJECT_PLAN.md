# Soulforge development plan

Source of scope: MasterPromt.txt §§1–26. Dependencies follow the numbers below. Every milestone requires a runnable desktop game, typecheck, lint, relevant tests, browser smoke test and production build. Record evidence before advancing.

## Current state

Milestones 1–7 have functional implementations and automated verification. Milestone 8 has a playable local build, original procedural presentation, settings, audio, and Hosting preparation. Local QA is passing. Public release is pending the existing project's Web App configuration, email/password provider, reviewed rules, and explicit deployment approval.

The preview route is session-only. The account route saves to Firebase emulators in local emulator mode. No production project, provider, database, rules, or Hosting resource was changed during implementation.

Six unit/UI tests passed and Edge created, equipped and cast Cinder Arrow during a real wolf encounter. Chain unlock is supplied by milestone 6. Typecheck, lint and production build passed.

- Final automated coverage includes ten Vitest tests across eight files, two Edge browser scenarios against Auth/Firestore emulators, rules authorization checks and a production Hosting smoke test. ## Release limits and remaining validation

- The checked production project is `soulforged-34d3c`. It has anonymous authentication, a Firestore database and Hosting. It has no registered Web App and no enabled email/password provider. Production client configuration and deployment are pending.
- Prototype Security Rules protect document ownership, revisions and payload bounds. Progress is client-trusted and validated on application load. Review the rules before broad public sharing. Competitive or shared-world features require authoritative server-side rewards and combat.
- Original art uses low-poly procedural geometry and animation. Audio is synthesized. There are no third-party art or sound attribution dependencies. Expanded art direction can build on the working gameplay.
- The production smoke test measured approximately 29–36 FPS using forced software WebGL at 1280×800. This is not a measurement of the 60 FPS target on a capable gaming GPU. Hardware performance and additional browser/device coverage remain unverified. The build reports large engine/Firebase chunks; the scene and account routes load lazily.
- Runtime dependency audit has zero reported vulnerabilities. The full npm audit still reports eleven moderate development-tool advisories. Firebase app overrides keep one Node-compatible SDK instance, and the gRPC override resolves the runtime dependency advisory.
- No production release or paid service activation is authorized. Local development and emulators remain the review path.
